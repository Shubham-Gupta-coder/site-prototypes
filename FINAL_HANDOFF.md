## Hosting
The project preview service was repository-root GitHub Pages on
`Shubham-Gupta-coder/site-prototypes`, publishing `main` via GitHub’s generated
`pages-build-deployment` workflow (no checked-in deployment workflow exists).
Removing this Pages service retires every path: option previews, all v2–v9.6
previews and the root index. The generated workflow cannot be independently disabled (GitHub returns HTTP
422); deleting the Pages configuration removes its deployment trigger instead.
No checked-in workflow can recreate it. Deployment history is retained.

Project documentation identifies no other Pages repository created for this
project. `Shubham-Gupta-coder/shubham-site` has Pages already disabled; it is not
modified. Unrelated repositories/hosting are outside scope and untouched.

No production domain was selected and the site remains `noindex`. Publishing
later requires an intentional new hosting setup and indexing/domain decision.
Nothing has been posted to X. Old hosting links in preserved source, project
chrome and historical documentation are historical references, not live promises.
